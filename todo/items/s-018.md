# s-018: Hal sources that need more work

- Status: open
- Priority: P3
- Added: 2026-10-30

## What

Add the hal price sources found on 2026-10-29 that weren't ready:

- **Sivas:** weekly PDF with a text layer, only the newest four listed; server sends an incomplete TLS chain
  (bundle the Sectigo DV R36 intermediate, as for Gaziantep); no categories or units.
- **Elazığ:** `elazig.bel.tr/hal-fiyatlari-yazdir`, latest only, no units or categories, run-together names
  ("Armutbursa", "Muzithal").
- **Bingöl:** `POST bingol.bel.tr/api/vegetable` with `{"term":""}` returned an empty list overnight; check
  during Turkish working hours. Latest only, no units.
- **Konya Ereğli:** `eregli.bel.tr/hal-fiyatlari?type=sebze|meyve`, ~106 products, updated irregularly; times out
  from the UK but answered GitHub's runners.
- **Hatay:** five halls in one bulletin, but the PDFs are scanned images (needs text recognition, see s-015).
- **Antalya Gazipaşa:** `gazipasa.bel.tr/gunluk-hal-fiyatlari`, ~13 products, "tavsiye" prices.
- **Çanakkale Biga:** `biga.bel.tr/hal-fiyat-listesi`, last updated 2026-09-22.

## Why

More markets on the site; each of these has a working page but needs extra handling or is thin.

## Done when

Each is added as a source or ruled out with a reason.

## Notes

  Çayeli; Yozgat disallows all bots.
- `hal.gov.tr` (the national HKS averages) answered GitHub's runners on 2026-10-30 although it times out from
  the UK.
