# s-012: Make fetch failures visible

- Status: open
- Priority: P1
- Added: 2026-10-12

## What

`sebzehali/fetch.py` exits 0 unless every city fails, so a run where one or four cities error still shows green. Make the workflow step fail, or at least flag it, when any city errors. Also: one failing date currently abandons the remaining dates for that city, because the `try` wraps the whole per-city loop.

## Why

On 2026-10-12 İzmir produced nothing in the scheduled run and the run was green (see s-013). Nothing told anyone.

## Done when

A run in which any city raised an error is not reported as a clean success, and the summary names the city.

## Notes

- 2026-10-30: one failing date no longer abandons the city's other dates (fetch.py catches per date and still
  counts the city as failed). The exit code still says success unless every city failed: that part is open,
  and matters more now that there are 25+ markets.
